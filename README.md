# Контрольная работа №3

Тема: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

## Описание

Адаптивная версия учебного интернет-магазина на основе КР №1. Проект находится в отдельном репозитории и использует HTML и CSS без Bootstrap. JavaScript КР №1 для модального окна и формы дополнен доступной сводкой ошибок.

## Практическая работа №12

- Перенесена основа КР №1.
- Добавлен `css/responsive.css`, подключённый после `css/style.css` на всех пяти страницах.
- Проверен `viewport`.
- Применён Mobile First и медиазапросы с `min-width`.
- Адаптированы навигация, hero-блок и сетка карточек.
- На мобильном экране фильтр каталога стоит перед товарами, от 1024 px — сбоку.
- Добавлены изображения с `srcset`, `sizes`, `picture` и `loading="lazy"`.
- Форма идёт в одну колонку на телефоне и в две от 768 px; комментарий, согласие и кнопки занимают всю строку.
- Таблица помещена в `.table-wrapper` с горизонтальной прокруткой внутри блока.
- Модальное окно ограничено шириной и высотой экрана.

Сетка товаров: одна колонка до 640 px, две от 640 px, три от 1024 px и четыре от 1280 px. Hero-блок становится двухколоночным от 900 px.

## Изображения

На основе учебного SVG из КР №1 подготовлены варианты шириной 480, 640 и 960 px. Для первого товара используется `srcset` с `sizes`, для hero-блока — `picture` с выбором источника по ширине экрана. SVG остаётся векторным при любом размере.

## Проверка

Откройте `index.html` через Open in Integrated Browser в VS Code или в браузере. Проверьте все пять страниц на ширинах 360, 430, 768, 1024 и 1440 px.

Проверьте перестройку меню и карточек, положение фильтра, изображение товара, форму заявки, карточки характеристик на телефоне и таблицу на большом экране и открытие/закрытие модального окна. В DevTools Network с фильтром Img можно проверить загруженные изображения, а через `currentSrc` — выбранный источник.

## Практическая работа №13

Тема: «A11y-аудит и обеспечение доступности. Использование Lighthouse и анализ проблем доступности».

- Проверены семантика, заголовки, кнопки, ссылки и подписи полей на пяти страницах.
- Добавлен skip-link: первая ссылка по Tab переводит фокус к `main`.
- Текущая страница меню обозначена `aria-current="page"`.
- Видимый фокус усилен до 3 px.
- Уточнены alt-описания упаковки товара.
- Подсказка формата телефона связана с полем через `aria-describedby`.
- Сообщение об успехе имеет `role="status"`; для зелёного текста выбран контраст 6,09:1 на фоне сообщения.
- В таблице добавлены заголовки строк `th scope="row"`; область прокрутки доступна с клавиатуры и имеет название.
- Проверены открытие диалога с клавиатуры, ввод в поля, закрытие по Escape и возврат фокуса на кнопку.

## Самостоятельные доработки

- Над формой выводится текстовая сводка ошибок со ссылками на поля. Ссылка переводит фокус в нужное поле.
- После первой отправки список обновляется при вводе: исправленные ошибки и `aria-invalid` убираются. Правильное заполнение проверено до сообщения об успехе.
- `prefers-reduced-motion` отключает плавную прокрутку при соответствующей системной настройке.

## Lighthouse

Аудит выполнен во вкладке Lighthouse DevTools встроенного браузера VS Code, категория Accessibility, мобильный режим. Использован Lighthouse 13.3.0 и локальный HTTP-сервер.

- `index.html` — 100/100: [отчёт](lighthouse/accessibility-index.html).
- `catalog.html` — 100/100: [отчёт](lighthouse/accessibility-catalog.html).
- `order.html` — 100/100: [отчёт](lighthouse/accessibility-order.html).

HTML-отчёты сохранены в `lighthouse/`. Автоматическая проверка дополнена ручной: Tab, skip-link, видимость фокуса, работа формы, сводка ошибок и модальное окно.

## Практическая работа №14

Выполнена итоговая проверка КР №3: структура проекта, подключение CSS и viewport, пять страниц, responsive images, формы, таблица, клавиатурная навигация, доступность и отчёты Lighthouse.

Самостоятельные доработки к сдаче:

- До 640 px характеристики товара представлены удобными карточками через `dl`, `dt`, `dd`; от 640 px показывается таблица. На каждой ширине доступно только одно представление.
- На странице контактов добавлена форма обратной связи. Она использует уже существующую проверку формы, сводку ошибок и сообщение об успехе, без нового JavaScript-файла и без отправки на сервер.
- Дополнительно проверены изменённые страницы `product.html` и `contacts.html` через Lighthouse DevTools VS Code: Accessibility — по 100/100.
- Для всех пяти страниц проверены ширины 360, 430, 768, 1024 и 1440 px; переполнения нет. Модальное окно помещается на всех пяти ширинах.

Дополнительные отчёты: [страница товара](lighthouse/accessibility-product.html), [контакты](lighthouse/accessibility-contacts.html).
